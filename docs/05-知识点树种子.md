## 0. 规范与使用说明

### 0.1 用途
1. **AI 打标候选集**：拍照录入（`P-02`）与 AI 出题（`P-09`）时，客户端按档案的“学段 + 学科”筛选本树中的**叶子节点（`叶子=1`）**注入 Prompt，AI 为每道题选择最匹配的 1–3 个叶子 ID。
2. **薄弱点聚合**：本地分析引擎沿树结构自底向上聚合错题数、加权错误率与薄弱度（见开发文档 §9.4）。
3. **版本演进**：本文档通过 `tool/build_kp_tree.dart` 解析为 `assets/knowledge/kp_tree_v1.json` 随 App 发布；后续更新递增 `treeVersion` 并附带迁移映射。

### 0.2 编码与字段规范
- **学段代码**：`p`（小学）、`m`（初中）、`h`（高中）。
- **学科代码**：`chn`（语文）、`math`（数学）、`eng`（英语）、`phy`（物理）、`chem`（化学）、`bio`（生物）。
- **ID 格式**：
  - 根节点：`{学科}.{学段}`（如 `math.m`，层级 0，隐式根）
  - L1 模块：`{学科}.{学段}.{两位序号}`（如 `math.m.02`）
  - L2 主题：`{学科}.{学段}.{L1}.{L2}`（如 `math.m.02.03`）
  - L3 叶子：`{学科}.{学段}.{L1}.{L2}.{L3}`（如 `math.m.02.03.02`）
- **字段说明**：
  - `层级`：`1 / 2 / 3`；`叶子`：`1` 表示可供题目打标的叶子节点，`0` 表示聚合父节点（均为 L2 或 L3 作叶子）。
  - `建议年级`：如 `3-4`、`5-6`、`7`、`7-9`、`高一`、`高二`、`高三`。
  - `常见题型`：从协议 10 种 `kind` 中选 1–3 个（`choice / fill / match / classify / response / group / solve / draw / spatial / write`）。
  - `说明`：一句话明确范围或易错点，辅助 AI 区分相近节点。

## 附录 B：知识点树维护与版本迁移规范

1. **ID 永不复用**：一旦某个 ID 在已发布版本中出现，即使节点被拆分或合并，旧 ID 也绝不能再分配给其他含义的节点。
2. **新增节点**：在对应父节点下顺延序号（如已有 `04`，新增 `05`），递增 `treeVersion`。
3. **重命名 / 优化说明**：含义不变仅微调文案时，保留原 ID，直接更新 `name` 与 `description`。
4. **合并 / 废弃节点**：
   - 将旧节点标记 `deprecated: true`，并在 `replacedBy` 填入目标新节点 ID（一对多拆分时填最主要的父/替代节点或保留原节点由人工复标）。
   - App 升级 `treeVersion` 时，读取 `migrations` 数组执行本地 `UPDATE question_kp SET kp_id = replacedBy WHERE kp_id = oldId`（去重忽略冲突），确保已有错题与薄弱点历史不丢失。
5. **AI 候选集过滤**：注入 `P-02` / `P-09` 的候选列表仅包含 `isLeaf == true && deprecated == false` 的节点。
