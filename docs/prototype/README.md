# InoU · 产品高保真交互原型说明（v2.0 现代极简版）

> 本地离线独立版入口：[docs/prototype/index.html](./index.html)（零外部 CDN 依赖，双击或使用 Chrome / Edge 离线即可打开，支持平板/手机双视口与深浅色主题切换）

## 1. v2.0 现代极简设计升级要点

- **去噪与统一图标体系**：全面去除原生杂乱 Emoji，全界面统一采用 `1.65px` 等宽线性 SVG 图标体系与克制的圆点状态指示。
- **90-8-2 视觉克制原则**：90% 低饱和中性画布 + 发丝线分割（消除重框卡片嵌套）、8% 柔和主色底衬（助学/英雄入口）、2% 实体强调色严格保留给当前页面唯一主按钮。
- **48px 极简工作台顶栏**：将原先平铺的多颗场景按钮收敛至右上角 **`场景直达 ▾`** 下拉菜单，配合 `平板端 | 手机端` 分段切换与 `PRD 标注` 开关，呈现干净的高科技产品控制台质感。
- **AI 思考过程渐进式披露**：将 `StudyCoachAgent` 诊断工具链与 `AntiSpoilerHook` 工具拦截日志收敛为可点击展开的微交互折叠条（默认静默展示保护状态，点击按需展开底层参数）。

## 2. 双端自适应对照

| 视图 | 手机端（Compact `390×844`） | 平板端（Expanded `1160×750`） |
|---|---|---|
| **顶层导航** | 底部 `58px` 毛玻璃 `NavigationBar` + 右下角诺诺悬浮球 | 左侧 `204px` `NavigationRail` + 底部助学/设置入口 |
| **首页** | 诺诺伴学卡 + 双英雄入口 + 待处理条 + 薄弱点 TOP3 | 主区双列英雄卡与待办 + 右侧常驻诺诺与学科雷达图 |
| **原图对照校对** | 上下分栏，顶部题号胶囊快速切换 | 左试卷原图 `bbox` + 右 Linear 风格发丝线属性检查器 |
| **常规数字化做题** | 顶边 `3px` 进度条 + 单题专注卡 + 数学符号键盘 | 三栏：题号导航 / 中央做题画布 / 右侧防剧透提示栏 |
| **手写纸质模式** | 支持切换并给出推荐平板提示 | 左悬浮胶囊工具栏 + 重排 A4 考卷 + 右草稿区与红笔改判 |

## 3. 五分钟核心走查动线

1. 打开顶部 **`场景直达 ▾`**：依次体验 **首次引导向导**、**拍照与原图对照校对 (`F1.3`/`F2.7`)**、**常规数字化做题**、**平板手写纸质与 AI 批改 (`F4.2`/`F5.5`)**、**诺诺老师防剧透导学 (`F10.4`)**、**薄弱点 AI 诊断专练 (`F9.3`)**。
2. 点击顶部 **`PRD 标注`** 切换琥珀色设计标签，查看核心页面背后的产品决策说明。
3. 点击右上角深浅主题按钮（独立版可用），验证重排 A4 纸面 `#FFFEFA / #1C2029` 与 `<canvas>` 笔迹在切换主题时自适应重绘且不丢失手写数据。
